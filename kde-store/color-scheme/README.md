# Arterial — Color Scheme

A KDE Plasma color scheme: black content surfaces, dark-grey chrome, arterial-red accents.
Errors use orange-red so they stay distinct from the accent.

![preview](preview.png)

- **Views** `#0a0a0a` · **window chrome** `#121212` · **buttons** `#1b1b1b`
- **Accent** `#8b0000` · **edge/hover** `#b30000` · **selection** deep red
- Includes `[Colors:Header]`, `[Colors:Complementary]`, `[WM]` and an `AccentColor`.

## Install

Copy and apply:

    mkdir -p ~/.local/share/color-schemes
    cp Arterial.colors ~/.local/share/color-schemes/
    plasma-apply-colorscheme Arterial

Or: System Settings → Colors → import `Arterial.colors`.
